# Smart Community Safety App

Flutter-based mobile app for community safety — report incidents, view safety hotspots on a live map, receive alerts, and trigger emergency SOS.

## Features
- Incident reporting with photos, GPS location, and categories
- Interactive safety map with hotspots and live incident updates
- Real-time alerts and daily safety summaries
- Analytics dashboard with incident trends
- One-tap emergency SOS with location sharing
- Email/PIN authentication and user profiles

## Tech Stack
Flutter · Dart · Provider · SQLite/Hive · Google Maps · Geolocation

## Run
```
flutter pub get
flutter run
```
