# 🛡️ Smart Community Safety App

A Flutter-based mobile application designed to improve community safety by allowing users to report incidents, receive alerts, view safety hotspots, and access emergency features.


## 📱 Project Overview

The Smart Community Safety App is developed using Flutter and follows modern mobile application development practices. The application provides an easy-to-use platform for reporting incidents, monitoring nearby risks, and improving neighborhood security.


## ✨ Features

### User Authentication

* Email/PIN Login
* User Registration
* Secure Authentication

### Dashboard

* Safety Alerts
* Incident Statistics
* Recent Reports

### Incident Reporting

* Add Incident
* Upload Photos
* GPS Location
* Category Selection
* Description
* Edit/Delete Reports

### Interactive Safety Map

* Google Maps Integration
* Unsafe Hotspots
* Live Incident Updates
* Radius & Category Filters

### Community Alerts

* Nearby Notifications
* Daily Safety Summary

### SOS Emergency

* One-Tap SOS Button
* Emergency Alarm UI

### User Profile

* Profile Picture
* Dummy CNIC Verification
* Trusted User Verification

### Search & Filters

* Filter by

  * Category
  * Severity
  * Date
  * Distance

### Analytics Dashboard

* Incident Statistics
* Trend Graphs
* Location Analysis
